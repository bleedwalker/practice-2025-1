# Проектная практика

## Задание на проектную практику

### Введение
Задание на проектную (учебную) практику разработано для студентов первого курса, обучающихся по направлениям подготовки, связанным с информационными технологиями и информационной безопасностью. Трудоёмкость практики составляет 72 академических часа. Задание может выполняться индивидуально или в составе группы до 3 человек. Для управления версиями будет использоваться Git, для написания документации — Markdown, а для создания статического веб-сайта — языки разметки HTML и CSS, но опционально допускается использовать генераторы статических сайтов, такие, как Hugo. В качестве платформы для размещения репозиториев допустимо использовать как GitHub, так и GitVerse. Также предусмотрено взаимодействие с организациями-партнёрами, включая стажировки.

---

### 1. Базовая часть задания

#### Настройка Git и репозитория
- Создайте личный или групповой репозиторий на GitHub/GitVerse.
- Освойте команды: `clone`, `commit`, `push`, `branch`.
- **Ожидаемое время**: 5 часов.

#### Написание документов в Markdown
- Оформите все материалы проекта в Markdown.
- **Ожидаемое время**: 5 часов.

#### Создание статического веб-сайта
- Используйте HTML/CSS или Hugo.
- Обязательные страницы:
  - Главная (аннотация проекта).
  - О проекте.
  - Участники (личный вклад).
  - Журнал прогресса (минимум 3 поста).
  - Ресурсы (ссылки на материалы).
- **Ожидаемое время**: 14–22 часа.

#### Взаимодействие с партнёрами
- Организуйте онлайн-встречу/стажировку.
- Напишите отчёт в Markdown.
- **Ожидаемое время**: 8 часов.

---

### 2. Вариативная часть задания

#### Вариант 1: Кафедральное задание
- Выполните базовую часть + индивидуальное задание.
- **Ожидаемое время**: 32–40 часов.

#### Вариант 2: Практическая реализация технологии
- Исследуйте технологию из [codecrafters-io/build-your-own-x](https://github.com/codecrafters-io/build-your-own-x).
- Создайте руководство с примерами кода и схемами.
- **Ожидаемое время**: 32–40 часов.

#### Вариант 3: Вклад в открытый проект
- Найдите проект с 50+ звёздами на GitHub/GitVerse.
- Исправьте баг/добавьте функцию.
- **Ожидаемое время**: 32–40 часов.
